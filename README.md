# Hyperlocal Delivery Rider Pool

A full-stack delivery operations platform for managing local delivery capacity, rider availability, authentication, and real-time operations.

## Preview

🌐 **Live Demo:** https://hyperpool-ev9uu3kr.manus.space/

## Tech Stack

- React 19 + Vite
- TypeScript
- Express + tRPC
- Drizzle ORM + MySQL
- Tailwind CSS + Radix UI
- Vitest

## Features

- Rider availability management
- Delivery capacity coordination
- Authentication & authorization
- Real-time updates
- Backend API with tRPC
- MySQL database
- Responsive dashboard

## Project Structure

```text
client/     → React frontend
server/     → Express, tRPC & backend services
